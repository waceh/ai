### 개요

CLAUDE.md는 프로젝트 규칙·컨벤션·빌드 명령 같은 지속적인 컨텍스트를 담아, **Claude Code**가 세션을 시작할 때마다 자동으로 읽어들이는 마크다운 파일입니다.

비유하면, CLAUDE.md는 "새 팀원에게 매번 설명하는 온보딩 문서를 파일로 박아둔 것"입니다. 매번 새로 설명하는 대신, 반복해서 알려줘야 할 사실(빌드 명령, 코드 스타일, "항상 X 하라" 규칙)을 한 번 적어두면 **Memory**처럼 세션마다 다시 주어집니다. 내용은 일반 **Prompt**와 함께 컨텍스트 앞부분에 삽입됩니다.

유의사항: CLAUDE.md ≠ Memory 전체가 아닙니다. CLAUDE.md는 사람이 직접 쓰는 고정 지침 파일이고, Memory는 세션 간 유지되는 맥락이라는 더 넓은 개념(자동 기록되는 항목까지 포함)을 가리킵니다.

### 사용목적

새 세션마다 프로젝트 구조·빌드 방법·코딩 컨벤션을 반복 설명하지 않으려는 목적입니다. 특히 여러 사람·에이전트가 같은 프로젝트를 다룰 때 일관된 규칙을 강제할 수 있습니다.

### 동작/구조

프로젝트 루트(또는 상위 디렉터리)에 `CLAUDE.md` 작성 → Claude Code가 세션 시작 시 파일을 읽어 Prompt 컨텍스트에 포함 → 이후 모든 응답이 이 지침을 따름 → 새로운 반복 규칙이 생기면 파일에 추가해 다음 세션부터 반영.

- **Claude Code**: CLAUDE.md를 읽어들이는 호스트
- **Memory**: CLAUDE.md가 채우는 세션 간 맥락 유지 개념
- **Prompt**: CLAUDE.md 내용이 삽입되는 대상
