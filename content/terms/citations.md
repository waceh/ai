### 개요

Citations(Citations API)는 Claude 응답의 각 문장을 원본 문서의 정확한 위치(문자 단위 오프셋)에 매핑해, 근거를 검증 가능하게 만드는 Claude API 기능입니다.

비유하면, "답변 옆에 각주 번호와 원문 페이지를 자동으로 달아주는 것"입니다. **RAG** 파이프라인에서 검색 결과 문서를 일반 텍스트 대신 인용 지원 콘텐츠 블록으로 전달하면, Claude가 응답에 원문을 직접 인용하며 구조화된 인용 객체(문서 인덱스, 문자 오프셋, 원문 발췌)를 함께 반환합니다. PDF·plain text 등 지원 형식의 문서를 인용 소스로 쓸 수 있습니다.

유의사항: Citations ≠ RAG 자체입니다. RAG는 관련 문서를 검색해 컨텍스트에 넣는 전체 패턴이고, Citations는 그렇게 넣은 문서에서 Claude가 실제로 어느 부분을 근거로 답했는지 API 레벨에서 검증 가능하게 표시해주는 기능입니다. 프롬프트로 "출처를 밝혀줘"라고 부탁하는 것보다 관련 인용을 뽑는 정확도가 더 높다고 Anthropic은 평가합니다.

### 사용목적

생성된 답변이 실제로 어느 문서·어느 문장에 근거했는지 사용자가 확인해야 하는 경우(법률·의료·리서치 문서 Q&A)에, hallucination 위험을 줄이고 근거를 검증 가능하게 만들고 싶을 때 씁니다.

### 동작/구조

RAG 검색 결과 문서를 인용 지원 콘텐츠 블록으로 요청에 포함 → Claude가 답변 생성 시 원문 발췌를 직접 인용 → 응답에 문서 인덱스·문자 오프셋·인용 텍스트를 담은 구조화된 citation 객체 포함 → 클라이언트가 이를 이용해 답변 문장과 원문 위치를 연결 표시.

- **RAG**: Citations가 근거를 표시해주는 검색 파이프라인
- **Evaluation**: 인용 정확도를 채점 기준에 포함할 수 있음
- **Observability**: 어떤 근거로 답했는지 추적하는 수단으로 활용
